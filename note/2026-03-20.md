## Diffusion Model

I generate the target in such a way:

```
field1: value1
field2: value2
...
```

Then I build a decoder only model that has in input `{S_text}. {L_text}`.
And it is conditioned on some empty prediction e.g.

```
field1:
field2:
...
```

I make it predict the output 4/8 times and I evaluate and backpropagate the
prediction 2/3 times for each sample.

## NER + Diffusion Model

I generate the target in a NER way:

```
some field1{important word}
```

And then I use a diffusion model, such that I generate the tokens for one
field at the time conditioned on the words identified by the NER classifier.

## RL with Diffusion

The input is divided in episodes, where each step is made by a token in
`{S_text}. {L_text}`. At each step the agent receive a token in input and it can
perform two actions:
1. Skip
2. Write

The agent has a "book", every time the agent pick `write` and the environment
check the book with the solution in the format:

```
field1: value1
field2: value2
...
```

For every field that is correct and wasn't there before there is a reward of 1.
For every field that is wrong and it was empty is a loss of 1.
For every field that is wrong, but was right there is a loss of 2.

Of course you can change the losses and calibrate them.
Therefore, the agent decides when to activate a diffusion model, that works with
few tokens. To make it easier, each token can corresponds to a word.

## NER + RL

Similarly to the previous point, since the agent needs to figure out when to
write and when to skip, it makes sense that the reward is managed through a NER.
Indeed, I know beforehand what token should be selected, and so maybe I can
provide better insights to the agent, meaning that I can assign better rewards.
